# 活库区（data）

**这里放"机器要用的大文件"**：数据库、下载缓存、锁与状态文件 —— **可再生**、**不外发**、**不是记忆**。

| 项 | 规则 |
| --- | --- |
| 放什么 | 数据库/索引单文件、上游下载缓存、锁与状态文件 |
| 判断标准 | **机器用**的（人不读它） |
| 命名 | 按种类：`data/<种类>/`，**不带日期** |
| 体积/行数 | 交给 `STATE.md` 的**采集器**生成，别手写进文档 |
| 归档 | 一般**不进** `archive/`（可再生）；真正不可再生的原始数据才进 `archive/` |

## 规则

- **单写者**：同一份可变资源同一时刻只允许一个写进程。看到锁文件就别并发，也别手删锁。
- **可再生，但别随手删**：删之前确认能重新生成，并把**重建成本**（耗时/流量）写进记忆或 `handbook/`。
- **不外发**：不进外部副本、不进 git；对外发布前先跑 `memory_doctor.py --only secrets`。
- **别把结论放这里**：过程与结论写 `memory/`，这里只放机器读的东西。
- 超过 `.memory-kit.toml` 里 `[scan] max_file_bytes` 的文件会被体检跳过文本检查（有意为之，不会被当文本读爆内存）。
