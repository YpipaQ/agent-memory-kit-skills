# 工作记忆约定（memory）

本目录是工作区的**冷记忆**：在办的事、试出的结论、待办都写这里。
热记忆是根目录 [`AGENTS.md`](../AGENTS.md)，但它**只放提示词、规则、长期习惯**；事实见 [`settings.md`](settings.md)，
数字见 [`STATE.md`](../STATE.md)，定型流程见 [`handbook/`](../handbook/README.md)。

## 目录规则

```
memory/
├── README.md              # 本文件：约定 + 索引
├── settings.md            # 环境事实（端点/Key/路径/模型/口径坑），半稳定、手工维护
└── YYYY-MM-DD/            # 一天一个文件夹（按写入当天日期）
    └── 主题.md            # 文件名 = 主题；同一天同一类事情**就地改这个文件**
```

- **同类合并**：同一天、同一类事情**在同一个文件上修改**，不要一天摊一堆文件。
- **跨天续写**：在新日期文件夹里开新文件，开头写明"接 `YYYY-MM-DD/xxx.md`"，不回头改旧文件。
- **150 行硬上限**：任何笔记/手册超过 **150 行必须压缩**（删过程史、细节外移到脚本/`handbook/`），
  末尾留一行「压缩记录：删了什么、去哪了」。体检会把它标成 ❌。
- 只读的原始数据（JSON/CSV/Parquet）放当天文件夹或 `scratch/`，文件名带来源前缀。
- **命名按时间**：`memory/` 与 `exchange/` 是按时间的两区；`scratch/`、`handbook/`、`archive/`、`trash/`
  一律**按种类**（例：`scratch/<种类>/`、`archive/<种类>/<快照日期>/`）。

## 分工

| 内容 | 去向 |
| --- | --- |
| 提示词、规则、长期习惯 | 根目录 `AGENTS.md`（热，唯一注入） |
| 环境事实：端点、Key、路径、模型名、口径坑、版本 | [`settings.md`](settings.md)（半稳定，手工维护） |
| **易变数字**：体积/行数、缓存、归档、磁盘、设备、白名单 | 根目录 `STATE.md`（**脚本生成，勿手改**） |
| 在办的事、试验矩阵、失败尝试、原始输出、待办 | `memory/YYYY-MM-DD/`（冷） |
| **已定型、可照做**的流程与结论（速查） | [`handbook/`](../handbook/README.md) |
| 出题 / 作答的受控交流（多智能体测试） | [`exchange/`](../exchange/README.md) |
| 要**再跑一遍**的探针 / 基准脚本及其产物 | [`scratch/`](../scratch/README.md) |
| **会被滚动窗口挤掉、不可再生**的数据快照 | [`archive/`](../archive/README.md)（含 manifest + sha256） |
| 用过且不再需要的文件 | [`trash/`](../trash/README.md)（`mv` 不 `rm`） |

## 写入时机

- 一次调查 / 调试 / 试验结束时就落盘，别攒到以后；**同类事情改同一个文件**。
- 新增文件后在索引表加一行；`AGENTS.md` 只在"规则或长期习惯变了"时才改。
- 不写密钥副本：Key 只出现在 [`settings.md`](settings.md) 或用户级凭据文件里。
- **结论前置**：超过 ~80 行的文档，开头 12 行内必须有「结论 / 怎么做 / 坑」，过程史往后放。
- **易变数字不手写**：交给 `STATE.md` 的生成脚本；半稳定事实写 `settings.md`。
- **定型就搬家**：彻底完善且实测通过的流程/结论 → `handbook/`，来源笔记压缩成指针。
- 改完文档跑体检：`python3 scratch/memory-tooling/memory_doctor.py`
  （断链 / 索引对齐 / 150 行硬限 / 结论前置 / 敏感串 / exchange 协议 / handbook 索引 / 命名）。
