# 项目区（projects）

**这里放"要构建、要长期演进"的东西**，但只按一种形态放：**一处真身 ＋ 登记卡**。

> **一句话**：**真身只有一处**（代码、测试、构建产物都在那，改动只在那里）；
> 本区只放一张 `README.md` 当**登记卡**（默认 ≤40 行，**只放指针**）。
> 形态由 `.memory-kit.toml` 的 `[projects] mode` 决定：

| mode | 真身在哪 | 本区放什么 | 什么时候用 |
| --- | --- | --- | --- |
| `embedded`（默认） | 本区 `projects/<名>/` | 项目本体 | 工作区就是项目的家（单人单机、小件） |
| `card` | 工作区外 `[projects] truth_root` | 一张登记卡 | 项目多、要跨会话/跨工作区复用、要给 agent 当技能 |

> `card` 模式下体检会核对 **卡 ↔ 真身**（`--only cards`）：卡在不在、卡里的真身路径指不指得到、
> 真身根下有没有**没登记的项目**。**判断类的事不查** —— 建不建、要不要外发、算不算退役，
> 见技能 `agent-memory-kit-skills` 的 `references/项目管理.md`（**自然语言的建议，人做决定**）。

## 规则

- **先 `scratch/` 后建项目**：新东西默认先放 [`../scratch/`](../scratch/README.md) 做功能小样
  （真数据、真通路、一两条端到端跑通）；**用户确认**要长期维护才"毕业"进本区。
  与 `scratch/` 相反，**本区不能整区删除**。
- **建一个项目（四步，两种形态都照这个走）**：
  1. **真身**着地（`embedded` 就在本区目录，`card` 就在 `truth_root/<名>/`）＋ 写 `README.md`
     （是什么 / 怎么跑 / 依赖什么 / 当前状态 / 最后验证日期）＋ `git init` 与 `.gitignore`；
  2. **可见性当场定**（`仅本机` / 私有远端 / 公开远端）—— **默认仅本机**；
  3. `card` 模式再在本区加 `projects/<名>/README.md` 登记卡（照 [`_登记卡模板.md`](_登记卡模板.md)）；
  4. 跑 `memory_query.py --rebuild --refresh`，条目进台账与活窗口。
- **项目里只放"能跑、能构建"的东西 ＋ README**：过程、结论、踩坑写 `memory/YYYY-MM-DD/`；
  项目 README **只放相对链接**指过去，**不复制结论**（防"同一句话两处写、改一处忘一处"）。
- **本区在 `card` 模式下不放代码**：卡里只写指针，运行说明写真身 README。
- **可见性就是保密等级**：要外发（私有/公开远端）时**先问用户**，推之前先过敏感串扫描；
  做法见技能 `agent-memory-kit-skills` 的 `references/隐私与密钥.md`。
- **目录名按种类、不带日期、定了别改**；改名要同步改所有引用（体检查断链）。
- 本区里若放了**别处的树**（某个技能 / 模板仓库的检出），它的相对链接按自己的布局解析、
  在工作区里必然断 —— 在 `.memory-kit.toml` 的 `[scan] exclude` 里排除该路径，别让它污染体检。
