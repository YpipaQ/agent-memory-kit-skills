# 删除区（trash）

**这里的文件随时可以整体删掉**，不要在这里放还需要的东西。

## 用途

- 用过、且判断"未来不会再读"的文件，直接移进来，而不是当场 `rm`。
- 主要留给**短期留档的测试产物**：临时脚本、一次性原始响应、模型输出、探针结果。
- 相当于一个回收站 + 观察期：放进来观察一阵，确认没人要就清空。

## 规则

- 目录结构：**`trash/<种类>/原文件名`** —— 按**种类**分（与 `scratch/` 同口径）。
  例：`trash/<种类>/`。同类再来一批时，文件名带日期避免撞名（`xxx-20261001.json`）。
- 移动而不是复制：`mv` 到对应种类目录；同名冲突时加序号后缀 `-2`、`-3`。
- 不放敏感信息：这里的文件不加密、不保证清理时机，含 Key / 私人数据的文件别往这儿扔 ——
  这类文件要按凭据处置流程处理（移出仓库 + 轮换）。
- 清理：确认无用后按种类整目录 `rm -rf trash/<种类>/`；整个 `trash/` 删掉也不影响任何配置与记忆。
